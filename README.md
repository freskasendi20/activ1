## 🌟 نظرة عامة (Overview)
تم تطوير **ActivKeyz** ليكون منصة رقمية متكاملة وليست مجرد صفحة هبوط (Landing Page). يوفر الموقع تجربة تسوق وشراء فاخرة وسلسة باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL)، مخصص لتوزيع تراخيص واشتراكات الذكاء الاصطناعي، البرامج الإبداعية، أدوات العمل والمكتب، وحزم البث الترفيهي بأسعار الجملة الرسمية وتسليم فوري خلال أقل من 60 ثانية.

## 🎨 الهوية البصرية والتصميم (Cyber-Neon Design System)

1. **تناغم الإضاءات والنيون (Perimeter Glowing Borders):**
   - تم بناء حدود نيون مضيئة ومحيطة (`daer maydoor`) لكل قسم ولجميع الكروت في الهيدر وبوابات الأقسام باستخدام تدرجات احترافية وألوان مخصصة لكل قسم:
     - 🤖 **الذكاء الاصطناعي (AI):** أزرق سايبر متوهج (`#00D2FF` و `#38BDF8`).
     - 🎨 **البرامج الإبداعية (Creative):** بنفسجي كهربائي (`#A855F7` و `#C084FC`).
     - 💼 **المكتب والإنتاجية (Office):** أزرق تقني ملكي (`#3B82F6` و `#60A5FA`).
     - 🎬 **الترفيه والبث (Streaming):** أحمر سينمائي نيون (`#EF4444` و `#F87171`).
     - 🎮 **الألعاب (Gaming):** أخضر إيميرالد مضيء (`#10B981` و `#34D399`).

2. **معالجة الخلفيات المزدوجة (Seamless Cosmic Background Blending):**
   - تم دمج صورتي الخلفية (`hero_bg_ultra.jpg` في الجزء العلوي و `lower_earth_bg_ultra.jpg` في الجزء السفلي) عبر أقنعة تدريجية ناعمة بنسبة 100% (`mask-image: linear-gradient`) مع طبقة نجوم متلألئة (`stars-layer`)، مما يلغي تماماً أي خطوط أو فواصل حادة على جميع الشاشات.

3. **تجربة هاتف استثنائية (Mobile-First Perfection):**
   - **كاروسيل سحب تفاعلي (Swipeable Deck):** تم تحويل كروت الهيرو الثلاثية الأبعاد في الموبايل من التكديس الضيق إلى كاروسيل أفقي ناعم يدعم اللمس مع خاصية التثبيت التلقائي (`scroll-snap-type: x mandatory`).
   - **قائمة هاتف زجاجية فاخرة (Luxury Drawer):** قائمة جانبية منزلقة بتأثير الزجاج المصقول (`backdrop-filter: blur(25px)`) تتيح الانتقال بين جميع صفحات المتجر بلمسة واحدة.

## 💳 طرق الدفع والتكامل المحلي (Local Payment Gateways)

يدعم المتجر التحويل اللحظي عبر أشهر وأسهل وسائل الدفع في مصر والشرق الأوسط:
* 📱 **فودافون كاش (Vodafone Cash):** تحويل فوري مع إرسال رسالة التأكيد عبر واتساب.
* ⚡ **إنستاباي (InstaPay Egypt):** تحويل بنكي لحظي برقم الحساب أو عنوان الدفع اللحظي (IPA).
* 💳 **البطاقات البنكية (Visa & Mastercard):** دفع آمن مشفر بمعايير 256-bit SSL.
* 💳 **بطاقات ميزة (Meeza):** دعم بطاقات الدفع الوطنية المصرية.
* 🪙 **العملات الرقمية (USDT / Crypto):** دفع رقمي عبر شبكات TRC20 وBEP20.

## ⚙️ المحرك البرمجي وإدارة البيانات (Data Engine & State)

* **قاعدة بيانات العميل السحابية (`products-data.js`):**
  - نموذج بيانات موحد يحتوي على 33+ منتج رقمي معتمد.
  - دوال تطبيع تلقائية تضمن توفر الوصف المطول (`fullDesc`)، دليل خطوات التفعيل (`activationGuide`)، وشروط الضمان المحددة لكل منتج.
* **إدارة السلة الموحدة (`nexa_cart`):**
  - حفظ السلة في `localStorage` بحيث تظل المنتجات محفوظة أثناء تنقل المستخدم بين صفحات `index.html` و `category.html` و `product.html`.
* **لوحة التحكم الحية (`dashboard.js` & `dashboard.html`):**
  - إمكانية إضافة منتج جديد بكل تفاصيله (العنوان، القسم، السعر بالجنيه والدولار، الصورة، دليل التفعيل، والضمان).
  - إمكانية تعديل وحذف المنتجات، أو استعادة القائمة الافتراضية بنقرة زر واحدة.
  - جميع التعديلات تنعكس فورياً في الواجهة الأمامية دون الحاجة لإعادة تحميل الخادم.

## 🛠️ كيفية التشغيل والاستخدام (Getting Started)

المشروع مصمم ليعمل كـ Single/Multi Page Vanilla Architecture خفيف وسريع للغاية بدون أي حاجة لبيئة Node.js معقدة أو أدوات بناء:

### 1. التشغيل المحلي (Local Running)
* يمكن فتح أي ملف `.html` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox, Safari).
* أو تشغيل خادم محلي خفيف مثل:
  * إضافة **Live Server** في VS Code / Antigravity IDE.
  * أو باستخدام Python من موجه الأوامر:
    ```bash
    python -m http.server 8080
    ```
    ثم فتح: `http://localhost:8080`

### 2. النشر السحابي (Production Deployment)
* المشروع جاهز 100% للرفع المباشر على منصات الاستضافة السحابية مثل:
  - **GitHub Pages**
  - **Vercel**
  - **Netlify**
  - **Cloudflare Pages**
  - أي سيرفر استضافة cPanel أو VPS تقليدي (Apache / Nginx).
